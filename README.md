# Ibrahim Nurudeen Shehu portfolio

React implementation of the three approved Stitch designs.

## Run locally

```bash
npm install
npm run dev
```

## Pages

- `/` — portfolio home
- `/projects/case-study` — reusable project case study template
- Any other path — 404 page

The Stitch HTML exports are in `src/designs/`. Tailwind compiles their original classes and theme tokens locally.

Project details, profile photo, CV files, contact details, and external links are placeholders. The automation demo is a simulation, and the contact form is not connected to a delivery service.
